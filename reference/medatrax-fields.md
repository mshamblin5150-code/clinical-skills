## Notes to capture while filling this in

- Does Medatrax take a free-text note body, or only discrete fields?
- If free-text: is there a character limit, and does it accept Markdown or plain text only?
- Which code sets does it want — ICD-10-CM, CPT, both? Free entry or picklist?
- What are the encounter/visit type options (the exact picklist strings)?
- What patient demographics does it require (age band vs exact age, sex, race)?
- How are clinical hours attributed — per encounter, or logged separately by shift?
- Is there a preceptor sign-off step, and what does it need from the entry?
