# Worksheet grammar positive control

This is the fresh one-case `icd10-cpt` run required by issue #1104. It was
generated from the existing committed `filled-anchor/notes/case-01.md` input
after the issue's skill edits landed, then retained byte for byte after a fresh
non-authoring pass accepted its anchors, provenance, code descriptors, and
worksheet shapes. The upstream `filled-anchor/notes/` run itself has two site
names redacted from nine of its twelve notes. This is a kept run record, not a
set and not a reference note.

Earlier private attempts remain findings about the generation process rather
than material to tune: one selected a case with no filled-anchor population,
one received paraphrased input that could not support verbatim anchors, and one
carried two physical-line transcription errors. None of those attempts is
committed. The committed worksheet is the first separately checked pass that
cleared the current skill without being edited after generation.

The paired source note is committed separately and may itself be incomplete or
wrong; retaining this worksheet does not endorse that upstream note. This is a
positive control for worksheet grammar only. Under issue #1139's later
descriptor-agreement rule it is deliberately retained as a **divergent run**:
its quotations do not establish every descriptor it proposes. The independent
agreement control retains an exact copy with its paired note and blind reader
record under `fixtures/descriptor-agreement-negative-control/`.
