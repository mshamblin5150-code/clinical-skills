# Guideline recommendation-label fixture

`ada-changelog-prefixes.txt` holds the shortest complete prefixes needed to test
the changelog-shape floor against real members. They were reduced from the ADA 2026
recommendation record rebuilt from pages 12–13 on 2026-08-29. The rest of each label
was removed because the test needs the marker, reference, auxiliary verb, and
participle only; it does not need or preserve the society's recommendation prose.

This is public guideline material and contains no patient information.
