# Coursework style controls

These are scrubbed structural derivatives of finished coursework from `output/` and the matching
discussion-reply runs. Course numbers, people, dates, sources, URLs, and substantive prose were
removed. The paragraph, quotation, heading, and reference-boundary shapes remain because those are
the inputs the `narrative-body` row reads.

The Markdown files are committed real-member controls for the discussion graders. The Word
document XML is the corresponding scrubbed structural derivative for the course-assignment DOCX
grader; its test places those committed bytes into a valid package before calling the public grader.
The private finished populations remain supplemental measurements; a clean checkout still exercises
each public command against these controls.
