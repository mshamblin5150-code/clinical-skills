## Symbols

| Shorthand | Expansion |
| --- | --- |
| `c/o` | complains of |
| `s/p` | status post |
| `w/`, `w/o` | with, without |
| `2/2` | secondary to |
| `r/o` | rule out |
| `+` / `-` | positive for / negative for |
| `↑` / `↓` | increased / decreased |
| `→` | leading to, progressing to |
| `x` | for (duration), e.g. `x3d` = for three days |
| `q`, `qd`, `bid`, `tid`, `qid` | every, daily, twice daily, three times daily, four times daily |
| `prn` | as needed |
| `NKDA` | no known drug allergies |
